# Who Can Do What

A simple guide to the 6 staff roles in the system and what each one is allowed to do.

**Roles, from most to least access:**
Super Admin → Admin → Business Head → Manager → Branch Manager → Staff

✓ = can do this &nbsp;&nbsp; ✓ (own branch) = can only do this for their own branch &nbsp;&nbsp; — = cannot do this

| What they can do | Super Admin | Admin | Business Head | Manager | Branch Manager | Staff |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| Log in and use the app | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| View orders | ✓ | ✓ | ✓ | ✓ | ✓ (own branch) | ✓ (own branch) |
| Accept an order | ✓ | ✓ | ✓ | ✓ | ✓ (own branch) | ✓ (own branch) |
| Create or edit a manual order | ✓ | ✓ | ✓ | ✓ | ✓ (own branch) | — |
| Settle, archive, or delete an order | ✓ | ✓ | — | — | — | — |
| View the menu | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Update the menu from the POS system | ✓ | ✓ | — | — | — | — |
| View the list of branches | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Add or edit a branch | ✓ | ✓ | — | — | — | — |
| View sales reports and analytics | ✓ | ✓ | ✓ | ✓ | ✓ (own branch) | — |
| Change app-wide settings (VAT %, fees, alerts) | ✓ | ✓ | — | — | — | — |
| View the list of staff accounts | ✓ | ✓ | ✓ | ✓ | — | — |
| Create staff accounts, edit roles, reset passwords | ✓ | ✓ | — | — | — | — |

## Good to know

- **"Own branch" roles** (Branch Manager, Staff) only ever see orders, reports, and manual-order actions for the one branch they're assigned to — never other branches.
- **Business Head currently has the exact same access as Manager.** There's no feature in the app today where the two roles are treated differently — worth checking with the team whether Business Head is supposed to have extra access that hasn't been built yet.
- **Only Admin and Super Admin can manage staff accounts, settle/delete orders, or change app-wide settings** — these are the two "trusted" roles for anything sensitive.
